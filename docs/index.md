# IStaX Timing and TSN Demo

This documentation describes timing and Time-Sensitive Networking (TSN) demonstrations for the IStaX platform. It covers GNSS-referenced timing, PTP boundary-clock configurations, SyncE hybrid operation, and TSN features such as gPTP, traffic generation, credit-based shaping, time-aware shaping, and per-stream filtering and policing.

Use the timing demonstrations to establish and verify a stable network time reference before evaluating the TSN demonstrations that depend on synchronized devices and traffic endpoints.
